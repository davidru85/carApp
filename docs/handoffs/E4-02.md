### Owner-run screen-reader walkthrough (`D-226`)

Build: branch `story/E4-B1-product-surface` at `db7902a4`, Debug. Record device, OS version, app
language and date for each platform. Run every flow twice: device language English, then Spanish
(Spain); the expected announcements below are given as "English / Spanish". A screen reader adds
its own role words ("button", "heading", "switch", "botón", "encabezado", "interruptor"); the check
is that the label, the value and the role are all announced, not the exact phrasing.

Setup — Android: Settings › Accessibility › TalkBack › on (or hold both volume keys for 3 s).
Swipe right / left moves focus; double-tap activates; the TalkBack menu's "Headings" navigation
moves between headings. iOS: Settings › Accessibility › VoiceOver › on (or triple-click the side
button). Swipe right / left moves; double-tap activates; the rotor set to "Headings" moves between
headings.

#### F-1 First run (fresh install)
- [ ] A1 Welcome title is announced as a heading: "Welcome to carApp" / "Te damos la bienvenida a carApp".
- [ ] A2 The body is read once: "Save locally now, or sign in…" / "Guarda los datos localmente…".
- [ ] A3 iOS only: "Sign in with Apple, button" (system copy). Then "Continue with Google, button" /
      "Continuar con Google, botón"; "Continue without an account, button" / "Continuar sin cuenta, botón".
- [ ] A4 Activating "Continue without an account" announces "Loading" / "Cargando" while busy.
- [ ] A5 Cancel the Google picker: the error is announced without moving focus: "Sign-in was cancelled.
      You can try again." / "Se ha cancelado el inicio de sesión. Puedes intentarlo de nuevo."
- [ ] A6 The first-vehicle form title is a heading: "Create vehicle" / "Crear vehículo"; no back
      control is offered.
- [ ] A7 Each field announces its label: "Vehicle name" / "Nombre del vehículo", "Initial odometer (km)"
      / "Kilometraje inicial (km)", "Brand (optional)" / "Marca (opcional)", "Model (optional)" /
      "Modelo (opcional)", "Fuel type, Petrol" / "Tipo de combustible, Gasolina" with a pop-up/menu role.
- [ ] A8 An out-of-range odometer announces "Enter a value within the allowed range." / "Introduce un
      valor dentro del intervalo permitido." as soon as it appears.
- [ ] A9 "Save vehicle" / "Guardar vehículo" is reachable by swiping; while saving it announces
      "Saving" / "Guardando"; after saving, the detail opens with the vehicle name as a heading.

#### F-2 Vehicles
- [ ] B1 List title "Vehicles" / "Vehículos" is a heading. The backup status reads "Backup status:
      Synced locally" / "Estado de la copia: Sincronizado localmente"; the coloured dot is silent.
- [ ] B2 Each row reads the vehicle name and its odometer with grouping: "142,500 km" (English) /
      "142.500 km" (Spanish).
- [ ] B3 iOS: the add control is "Add vehicle, button" / "Añadir vehículo, botón" (not "Add" or "plus").
      Android: "Add vehicle" / "Añadir vehículo" floating button.
- [ ] B4 The Settings entry announces its name ("Settings" / "Ajustes", per `E4-01`).
- [ ] B5 Detail: "Vehicle details" / "Detalles del vehículo" heading (Android) or the vehicle name as
      title (iOS); the vehicle name is a heading; "Edit vehicle" / "Editar vehículo" and
      "Delete vehicle" / "Eliminar vehículo" are buttons. iOS: the overflow is "More actions, button" /
      "Más acciones, botón" and the add control is "New refuel, button" / "Nueva recarga, botón".
- [ ] B6 Delete asks for confirmation: "Delete vehicle?" / "¿Eliminar el vehículo?", the explanation,
      "Delete" / "Eliminar" and "Cancel" / "Cancelar"; Cancel keeps the vehicle.

#### F-3 Refuels
- [ ] C1 Form title "New refuel" / "Nueva recarga" is a heading; "Close" / "Cerrar" and "Save" / "Guardar" are buttons.
- [ ] C2 The date control reads "Date: <day>" / "Fecha: <día>" with the day in the device language.
- [ ] C3 The entry-method choices are announced with the selected one identified.
- [ ] C4 Litres and price fields announce their labels; typing 40 and 1,5 (Spanish) or 1.5 (English)
      makes "Calculated total" / "Total calculado" read "€60.00" / "60,00 €" (or the device currency).
- [ ] C5 "Full tank" / "Tanque lleno" is read with its help text and its on/off state as one switch;
      the same for "Missed refuels" / "Repostajes omitidos".
- [ ] C6 Saving a lower odometer opens the warning: title "Odometer looks inconsistent" / "El odómetro
      parece incoherente", the body, "Save anyway" / "Guardar de todos modos", "Cancel" / "Cancelar".
- [ ] C7 After saving, the entry row reads the date, the explanation ("No consumption: partial tank." /
      "Sin consumo: tanque parcial."), the facts ("142,500 km · 40.000 L · €60.00" / "142.500 km ·
      40,000 L · 60,00 €"), and each badge ("Partial tank", "Missed refuels", "Inconsistent odometer" /
      "Tanque parcial", "Repostajes omitidos", "Odómetro incoherente").
- [ ] C8 Double-tapping the row opens it for editing on both platforms.
- [ ] C9 With two full tanks the average reads "<value> L/100 km" with the locale's decimal separator,
      and "Historical average consumption" / "Consumo medio histórico" is a heading.

      permanentemente todos los vehículos y repostajes de la cuenta existente por los datos de este
