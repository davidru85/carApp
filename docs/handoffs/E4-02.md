### Owner-run screen-reader walkthrough (`D-226`)

Build: the head of `story/E4-B1-product-surface` under review (record the commit SHA), Debug. Record device, OS version, app
language and date for each platform. Run every flow twice: device language English, then Spanish
(Spain); the expected announcements below are given as "English / Spanish". A screen reader adds
its own role words ("button", "heading", "switch", "botón", "encabezado", "interruptor"); the check
is that the label, the value and the role are all announced, not the exact phrasing.

Setup — Android: Settings › Accessibility › TalkBack › on (or hold both volume keys for 3 s).
Swipe right / left moves focus; double-tap activates; the TalkBack menu's "Headings" navigation
moves between headings. iOS: Settings › Accessibility › VoiceOver › on (or triple-click the side
button). Swipe right / left moves; double-tap activates; the rotor set to "Headings" moves between
headings.

   show no switch until the stored settings are read. The owner selected the allowlist route (`B1`), so
