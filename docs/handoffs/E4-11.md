## Risks or Follow-ups

- Three `FirebaseConfigurationTest` tests, the `IosCompositionContractTest` Swift-factory test, the Analytics and
  Crashlytics contract tests and `contractCheck` assertions 37 and 46 scan the whole checkout and fail when a Git
  worktree lives inside it under `.worktrees/` (they see the sibling copy of the same files). They pass on a
  clean checkout and in CI. AGENTS.md tells agents to create worktrees there, so this is a latent trap; it is not
  fixed here and is worth a story.

- Already-installed builds keep the vulnerable bundle until reinstalled. There is no production release yet and
  release builds fail closed (`D-238`), so only `staging` and debug builds on the owner's devices are exposed.
