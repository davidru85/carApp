## Ready Check

- Backlog story: `E3-20` (`docs/BACKLOG.md`, story section and index row).
- Acceptance criteria reviewed:
  - an unsupported provider value is classified as a `MalformedPayload` quarantine record, not a
    page-level `RemoteError.InvalidArgument`, so the cursor advances past it;
  - a test feeds a document with an unsupported provider value and asserts a quarantine record and an
    advanced cursor.
- Dependencies checked: `E3-03` (the engine's quarantine path), `E3-19` (the push-side counterpart)
  and `E3-13` (`EntityType` in `:core:common`) are complete.
- Decisions checked: `D-208` (ADR-0209) is `Accepted` (option A, 2026-10-14): the integration carries
  an unsupported value as a reserved marker `{UNSUPPORTED_PROVIDER_VALUE_KEY: <type name>}` and
  `:core:sync` quarantines every marked document as `MalformedPayload` after the unsupported
  `schemaVersion` check. Applies `D-170` (raw pull boundary) and `D-174`.
- Normative sections reviewed: `docs/CONTRACTS.md §9.4`, `§9.5`, `§10`, `§16`, `§20.7`, the `§15.1`
  expect/actual allowlist for `untypedFields()`; `docs/SPECIFICATION.md §11` (TDD and its exemptions).
- Expected verification: integration unit tests of the total conversion, an end-to-end test through
  the real engine and database, a `:core:sync` marker-detection test and a controller quarantine test,
  and the complete `AGENTS.md` command. The Android and iOS `untypedFields()` actuals need a live
  provider and follow the provider-integration TDD exemption.
- Human review gates identified before work: gated paths `core/sync/**` and `docs/CONTRACTS.md`;
  gated topic "the synchronization algorithm or its state machine"; the story is marked "Human review
  required".
- Rule 0 acknowledged: chat replies for this story are in Spanish (es-ES) and every artifact it
  produces is in technical English.
