## Decisions Made

- `D-211` (ADR-0212): `SettingsStateHolder` lives in `:shared`.
- `D-212` (ADR-0213): each host reads its own app version natively.
- `D-213` (ADR-0214): "wait" withdraws the sign-out prompt and requests a `PullToRefresh` cycle.
- `D-214` (ADR-0215): a root-level host departure screen renders progress, failure and retry.
- `D-215` (ADR-0216): `PERMANENT` shows sign-out and account deletion; `LOCAL` and `ANONYMOUS` show
  one local-data deletion row.
- Design 06 contradicts the normative documents in six places, none of which is implemented
  (`docs/DESIGN.md §7`: the normative document wins): chevrons on the read-only units; a backup
  subtitle and an "Activa" chip that claim a remote copy (`D-193`) and offer no retry; "telemetría
  anónima", where `D-203` and `docs/CONTRACTS.md §16.1` say pseudonymous; no "delete local data" row
  for local and anonymous owners; a tagline that is extra copy; "v1.0.0" while both hosts ship
  `0.0.1`.
